# MicroBridge Tests
These are the tests for the MicroBridge project. The tests are designed to ensure that the functionality of the MicroBridge library is working as expected.

We use them in our CI/CD pipeline to automatically run tests on every commit and pull request. This helps us catch bugs early and maintain the quality of the codebase.

We also have a GUI test that mocks up CTK and allows us to test the GUI functionality of the MicroBridge library.

These can all be ran locally to make sure everything is working as expected before pushing changes to the repository.

The data in test_data is actual data used when developing the MicroBridge library
There is a mix of real and mock data, Most of it is real data generated by NDP.view2 for specific things to test functionality of a specific function or feature in MicroBridge. We also have a few real fully fledged ndpa files from scientists actual work, and the xml that should generate to reference off of.
